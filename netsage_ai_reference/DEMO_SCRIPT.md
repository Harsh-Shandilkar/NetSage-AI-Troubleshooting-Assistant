# NetSage AI Demo Script (5–10 minutes)

1. Introduce the problem and human-review safety rule.
2. Show the project folder and dataset.
3. Open the web assistant.
4. Paste a broken-network symptom and matching Packet Tracer output.
5. Show deterministic checker findings.
6. Show the AI's structured diagnosis.
7. Explain confidence and evidence.
8. Human reviewer accepts/edits/rejects the recommendation.
9. Apply the fix manually in Packet Tracer.
10. Re-run ping/show command to verify.
11. Show dashboard and Responsible AI log.
12. Close with limitations and future improvements.
