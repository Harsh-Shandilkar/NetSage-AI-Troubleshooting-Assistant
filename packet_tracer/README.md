# Cisco Packet Tracer Lab Package — NetSage AI

Welcome to the **Cisco Packet Tracer** lab package for **NetSage AI (Cisco Troubleshooting Assistant)**.

This folder contains all the architecture designs, device configurations, and fault injection recipes needed to construct and run the official simulation lab in Cisco Packet Tracer.

## 🚀 Quick Setup Instructions (5 Minutes)

1. **Open Cisco Packet Tracer** on your computer.
2. **Place the Devices**:
   - 2x **Cisco 2911** or **4321** Routers (R1-HQ, R2-Branch)
   - 2x **Cisco Catalyst 2960-24TT** Switches (SW1-Dist, SW2-Access)
   - 2x **Server-PT** (Web-Server, DNS-Server)
   - 4x **PC-PT** (PC-A, PC-B, PC-C, PC-D)
   - 1x **AccessPoint-PT** (AP-1) + 1x **Laptop-PT** (Wireless-Laptop)
3. **Connect Cables**:
   - Follow the port table in [TOPOLOGY.md](TOPOLOGY.md).
4. **Paste the Configurations**:
   - Click each device -> **CLI** tab -> copy & paste the corresponding .ios configuration from packet_tracer/configs/.
5. **Configure End Hosts**:
   - Follow [End_Devices_Setup.md](configs/End_Devices_Setup.md) for IP addresses, Subnet Masks, Gateways, and DNS.
6. **Save as .pkt**:
   - In Cisco Packet Tracer, click **File -> Save As...** -> Name it NetSage_AI_Troubleshooting_Lab.pkt.

## 🎯 How to Use with NetSage AI Web Assistant

1. Pick any case (e.g. C001, C002, C003, etc.) from [SCENARIOS_32_CASES.md](SCENARIOS_32_CASES.md).
2. Inject the fault on the specified device in Packet Tracer.
3. Run the verification command (e.g., show vlan brief or show interfaces trunk).
4. Copy the Cisco command output.
5. In NetSage AI (http://localhost:5173), select the Category, paste the Symptom & Output, and click **Run diagnosis**.
6. Compare the deterministic check and recommendations generated by NetSage AI with your Packet Tracer lab.
